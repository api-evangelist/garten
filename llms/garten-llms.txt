# garten

> garten (formerly Oh My Green) is a workplace food and wellbeing company founded in 2014 and headquartered in the San Francisco Bay Area, running office micro-kitchens and pantries, self-serve micro-markets with cashless kiosks, corporate catering and cafe management, and on-site and virtual wellbeing programming for employers across roughly twenty US metros. garten was acquired by the catering platform HUNGRY in 2025.

This file was generated by API Evangelist from the public garten surface — garten does not publish an llms.txt of its own (https://garten.co/llms.txt returns HTTP 404). It is an independent third-party profile, not a garten document.

garten publishes no developer portal, no API reference, no SDK and no OpenAPI. The only public machine-readable agent surface in the estate is a Model Context Protocol server on the Uscreen-powered garten TV property, and it is OAuth-gated.

## Agent surface

- [garten TV MCP server](https://tv.garten.co/mcp): JSON-RPC 2.0 MCP endpoint. Anonymous `tools/list` returns HTTP 401 with an RFC 9728 Bearer challenge; the tool set requires an authenticated introspection.
- [OAuth protected-resource metadata](https://tv.garten.co/.well-known/oauth-protected-resource): RFC 9728 document naming the MCP resource, its authorization server and its supported scopes.
- [OAuth authorization-server metadata](https://tv.garten.co/.well-known/oauth-authorization-server): RFC 8414 document — authorization, token, revocation, introspection and dynamic-registration endpoints, `authorization_code` + `refresh_token` grants, PKCE S256, resource indicators.
- Scopes: `content_analytics.read`, `finance_analytics.read`, `crm.read`, `cms.read`, `products.read`, `cms.write`, `crm.write`.

## Not published by garten

- No OpenAPI, Swagger, AsyncAPI, GraphQL schema or Protobuf definition on any host.
- No A2A agent card at `/.well-known/agent-card.json` or `/.well-known/agent.json`.
- No `security.txt`, no vulnerability-disclosure policy, no bug bounty and no trust center.
- No status page, changelog, deprecation policy, SDK, CLI, Postman collection or GitHub organization.
- The commerce API at `api.garten.co` / `client.garten.co` is a credentialed Spree/Solidus application: every anonymous call returns HTTP 401 `{"error":"You must specify an API key."}` and no documentation for it is published.
